# Deep Learning Overview

Deep learning is a subset of machine learning based on neural networks with many layers.
Key foundations include linear algebra, optimization, backpropagation, activation functions,
and regularization techniques.

Practical learning path:
1. Perceptron and feed-forward networks
2. Gradient descent and backpropagation
3. Convolutional networks for vision
4. Sequence models and attention
5. Transformers and modern LLM architectures
